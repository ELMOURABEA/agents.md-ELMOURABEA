We're from the [AGENTS.md](https://agents.md) project, and we wanted to share some best practices and updates that could help improve your AGENTS.md file:

### Recommended Improvements

1. **Structure**: Consider organizing your AGENTS.md with clear sections like:
   - Development environment tips
   - Testing instructions
   - PR/commit guidelines
   - Build and deployment instructions

2. **Specificity**: Include concrete examples and commands that agents can run directly
   - ✅ Good: `npm test -- --coverage`
   - ❌ Less helpful: "Run tests"

3. **Context**: Add information about:
   - Package manager preferences (npm, yarn, pnpm)
   - Common gotchas or pitfalls
   - Repository-specific conventions

4. **Keep it Updated**: As your project evolves, update AGENTS.md to reflect current practices
